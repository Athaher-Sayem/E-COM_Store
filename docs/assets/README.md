# Documentation assets

- `banner.svg`: original E-COM_Store project illustration, created for this repository.
- `storefront-preview.webp`: cropped/resized capture of this application's public demo storefront.
  This is a static example, not a live stock/availability feed. The visible AA-battery thumbnail
  incorporates **AA Batteries** by **ajay_suresh**, [source](https://commons.wikimedia.org/wiki/File:AA_Batteries_(51825378856).jpg),
  licensed [CC BY 2.0](https://creativecommons.org/licenses/by/2.0). The source photo was resized,
  orientation-normalized, converted to WebP, and displayed within the application's UI screenshot;
  the screenshot was cropped and converted to WebP. No endorsement is implied. Full catalog credits
  are retained in [`../../frontend/public/photo-credits.html`](../../frontend/public/photo-credits.html)
  and [`../../demo/catalog.json`](../../demo/catalog.json).
- `admin-preview.webp`: application overview capture made against the disposable browser-test API
  with **synthetic** Test Owner/Sample Store records. No real customer contact data, access tokens,
  passwords, or private lookup keys are pictured.
- Space Grotesk and DM Sans WOFF2 files: copied from the project's pinned `@fontsource` packages
  for offline use, with their original SIL Open Font License files alongside them. No font edits.

Only these deliberately reviewed public/synthetic previews are committed. Raw browser-test output
remains ignored and must not be published indiscriminately.
